本工程是一套面向商业级智能穿戴产品的完整嵌入式固件解决方案，采用 **STM32F407ZGT6（主控）+ ESP32-C3（Wi-Fi/BLE 协处理器）** 双 MCU 架构，构建了高可靠的 **多任务操作系统分层、LVGL 9 动效框架、cJSON 物模型上报** 与 **端到端 AES-128 加密空中 OTA 固件升级系统（含 Flash A/B 乒乓双区防掉电撕裂容灾引擎）**。

## 🌟 核心技术亮点 (Core Features)

### 1. 片外 W25Q64 双镜像空中 OTA 与 Flash A/B 乒乓容灾体系
* **AES-128-CBC 空中流式密文传输**：Wi-Fi 局域网全密文传输，防御 Wireshark 抓包嗅探与逆向破解；
* **片外 SPI Flash 双镜像存储 (W25Q64)**：暂存区（0x480000）与黄金固件备份区（0x400000），彻底释放内部 Flash，避免 Flash 擦写总线并发争死；
* **Flash A/B 乒乓元数据存储引擎（防掉电撕裂）**：
  * **彻底脱离 RTC 电池依赖**：将升级控制标志与元数据从片内 RTC 备份寄存器移出，独立映射至 W25Q64 的 4KB 扇区 Slot A（`0x500000`）与 Slot B（`0x501000`）；
  * **递增序列号 + 结构体自身 CRC32 双重仲裁**：每次更新向对侧旧槽位写入 `seq + 1` 与自身 CRC32；若写入或擦除中途遭遇断电，系统上电时自动舍弃 CRC 损坏区，无缝回退至上一有效槽位，彻底消除掉电撕裂（Tearing）；
* **全镜像 IEEE 802.3 CRC32 双重校验**：
  * **第一重（APP 侧）**：片外 W25Q64 暂存区 384KB 全镜像流式解密后校验，防御空中丢包、密钥错误与 Padding 错位；
  * **第二重（Bootloader 侧）**：热搬运后对 APP 运行区重新校验，防御 Flash 坏块与中途断电撕裂；
* **30 秒试运行守护机制 (Trial-Boot)**：新固件试运行 30s 稳定转正并持久化 `CONFIRMED` 魔数；若试运行期间崩溃重启超 3 次，Bootloader 自动拉起 W25Q64 黄金镜像执行紧急回滚自愈；
* **升级期间前台无感交互**：固件后台静默流式写入 W25Q64，物理按键与屏幕背光唤醒完全自由可用。

### 2. FreeRTOS 多任务调度优化与动态版本控制
* **动态版本统一管理 (`version.h`)**：集中定义主/次版本号，实时绑定启动横幅、MQTT 物模型 `ver` 字段与主表盘 LCD 顶部徽标；
* **多级电源管理与动态时序调度**：
  * 15s 无操作自动熄灭背光，进入待机态（Standby）；
  * 待机模式下挂起高频 100ms 渲染动画与遥测上报，任务调度降频，大幅释放 CPU；
  * 处于 FreeRTOS 空闲钩子时自动执行 Cortex-M4 内核级 `__WFI()` 休眠。

### 3. cJSON 动态物模型序列化与指令下行解析
* **FreeRTOS 内存钩子接管**：通过 `cJSON_InitHooks` 将 cJSON 底层内存分配重定向至 FreeRTOS 的 `pvPortMalloc` 和 `vPortFree`，复用 `heap_4` 算法的相邻空闲块自动合并机制，**彻底解决单片机堆内存碎片与泄漏隐患**；
* **物模型双向交互**：
  * **上行**：结构化动态组装传感器数据（温湿度、步数、六轴姿态、电池电压）并推送给客户端；
  * **下行**：实时解析手机端发来的 JSON 远程控制指令（如 Ping 探活、外设控制等）。

### 4. 两级非易失性参数持久化（Wear-Leveling 磨损均衡）
* 单扇区（Sector 11, 128KB）划分 **5400 个追加写入槽位**，单次保存仅需 0.08ms，扇区使用寿命放大 5400 倍（突破 5400 万次安全写入）；
* 掉电步数自动恢复、过夜跨天 0 点自动归零自检；
* 独立于 RTC 备份域的健康历史数据环形存储器（`history_storage`，2MB 容量）。

### 5. 系统高可维测性：CmBacktrace 堆栈回溯与故障自动反查
* **异常硬件栈帧自动提取**：通过汇编级接管 `HardFault_Handler`，自动区分并抓取 MSP / PSP 堆栈指针，提取崩溃瞬间的 CPU 核心寄存器（R0~R3, R12, LR, PC, PSR）与 SCB 状态寄存器（CFSR/HFSR/BFAR）；
* **FreeRTOS 任务级上下文追踪**：在 FreeRTOS 多任务环境下，自动识别崩溃发生在哪个具体任务（如 `Task_UI` 或 `Task_WiFi`），输出当前任务栈底基地址与最大栈深度；
* **PC 地址到源码行号全自动反查**：自主开发 `tools/fault_analyzer.py` 工具链，结合 `arm-none-eabi-addr2line` 将串口输出的 PC 调用栈一键映射至具体的 C 源码文件、函数名与代码行号，彻底终结嵌入式现场脱机“黑盒死机”难题。

## ⚡ 低功耗管理与优化演进路线 (Low Power Roadmap)

针对穿戴设备长续航需求，当前架构与后续可拓展的低功耗优化路线设计如下：

```
┌─────────────────────────────────────────────────────────────────┐
│                      系统低功耗分级管理方案                      │
├──────────┬────────────────────────────┬─────────────────────────┤
│ 运行模式 │ 外设与内核工作状态         │ 功耗表现与预期优化      │
├──────────┼────────────────────────────┼─────────────────────────┤
│ 交互活跃 │ CPU 168MHz 全速, 屏幕亮,   │ ~70mA - 110mA           │
│ (ACTIVE) │ 传感器 50Hz, Wi-Fi 数据上报│ (全功能满血响应 60FPS)  │
├──────────┼────────────────────────────┼─────────────────────────┤
│ 待机熄屏 │ 屏幕背光关, 挂起 UI 高频动 │ ~15mA - 25mA (当前现状) │
│(STANDBY) │ 效与 Wi-Fi 遥测, CPU WFI   │ 待机降耗约 70%          │
├──────────┼────────────────────────────┼─────────────────────────┤
│ 深度待机 │ ST7789 Sleep-In (0x10),    │ 预期可压降至 <2mA - 5mA │
│ (路线图) │ W25Q64 深度断电 (0xB9),    │ 续航从 3 小时飞跃提升至 │
│          │ MPU6050 陀螺仪休眠+WOM唤醒,│ 3 ~ 7 天 (300mAh 电池)  │
│          │ FreeRTOS Tickless+EXTI唤醒 │                         │
└──────────┴────────────────────────────┴─────────────────────────┘
```

* **屏幕控制**：熄屏时除了关断背光 GPIO 外，向 ST7789 发送 `0x10 (SLPIN)` 指令，切断屏幕驱动 IC 内部高压电荷泵（功耗从 8mA 直降至 <20μA）；
* **传感器降频**：熄屏待机时关闭 MPU6050 陀螺仪电源（`PWR_MGMT_2`，立省 3.6mA），仅保留低频加速度计，或启用运动检测中断（WOM, Wake-On-Motion）作为外部中断源唤醒 MCU；
* **存储深度断电**：非 OTA/非记录刷新期，向 W25Q64 发送 `0xB9` 深度掉电指令（静态电流 <1μA），读写前发送 `0xAB` 极速唤醒；
* **操作系统 Tickless Idle**：启用 FreeRTOS `configUSE_TICKLESS_IDLE`，在多任务均处于阻塞时停止 1ms SysTick 中断，改由低频定时器按需唤醒，彻底释放内核休眠潜能。

## 🚀 编译与 OTA 推送指南

### 1. 固件编译 (Keil MDK)
* 打开 `Project/STM32F407.uvprojx`，使用 ARM Compiler 5 构建生成 `Project/Objects/STM32F429.bin`。
* 打开 `Bootloader/Project/Bootloader.uvprojx` 构建生成 Bootloader 固件。

### 2. 空中 OTA 无线推送
确保手表正常开机并连上同一 Wi-Fi 热点（手表默认 TCP 端口为 8080）：

* **方式一：一键双击批处理（推荐）**
  直接双击根目录下的 `run_ota.bat`，直接按回车即可触发默认的 AES-128 加密空中推送。

* **方式二：Python 命令行推送**
  ```bash
  # 企业级 AES-128-CBC 密文空中升级
  python tools/ota_updater.py --ip 192.168.111.89 --encrypt

  # 标准明文兼容升级模式
  python tools/ota_updater.py --ip 192.168.111.89
  ```
